An AI tutor for your editor: ask in English or Bangla, get step-by-step explanations, and let the agent read, search and edit your project. Built by Md. Shafikul Islam (Cheradip), Bangladesh.

Install VS Code extension

1. What it does

The AI Tutor is the Cheradip AI companion inside VS Code (and VS Code–compatible editors). It explains concepts, writes and reviews code, and works through multi-step tasks with you — using Cheradip AI by default, or your own provider keys.

  • 💬 Chat — ask about your codebase with @ file / folder mentions
  • 🧭 Tutor mode — concept explanations, exam-style MCQ help and revision notes
  • 🤖 Agent mode — reads, searches and edits files with your permission
  • 🧩 Composer — multi-file changes in one go, with diffs and checkpoints
  • ✏️ Inline edit — change a selection in place (Ctrl+K style)
  • 🔐 Your own keys — OpenAI, Anthropic, Gemini, Groq, Mistral, DeepSeek or local Ollama

2. Install & sign in

  1. Open VS Code → Extensions (Ctrl+Shift+X)
  2. Search for Cheradip (publisher cheradip) and click Install
  3. Command Palette → Cheradip: Sign In
  4. Use the same phone/email and password as cheradip.com — no second registration
Existing Cheradip accounts are kept in sync automatically: an account created on cheradip.com already works in the extension, and an account created in the extension already works on the website — same credentials, both directions, no extra step.

Install free from the marketplace: Cheradip on the VS Code Marketplace.

3. Plans & billing
